# ЛР-2. Архитектура и данные -- «Управление возвратами»

Сквозная фича: **«Управление возвратами»** -- клиент оформляет возврат отправления (по одному и списком), отслеживает его и видит, что возврат делает с деньгами. Ядро -- возврат отправления, деньги -- его следствие в другом контуре.

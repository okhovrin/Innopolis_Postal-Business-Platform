## Сквозной пример

Клиент подаёт заявку. После проверки условий и удержания стоимости оформляется встречное отправление с собственным ШПИ. Когда отделение принимает его, возникает основание для окончательного списания. Если приём не состоялся и это подтверждено, удержание освобождается. В кабинете отдельно видны состояние заявки, последнее известное состояние посылки и статус расчёта. Отчёт строится по подтверждённым событиям и показывает, до какого момента обработаны данные ЛК.

Движение денег описано по учебному условию З-7; действующие правила расчётов для возвратных отправлений в материалах не установлены. Ссылки на занятия указывают на источник исходных сведений. Состояния, новые поля, контракты и эксплуатационные параметры ниже предлагаются в рамках проекта.

## Согласование решений

- Приём отправления подтверждает логистика. Он запускает окончательное списание; если ответ биллинга потерян, результат проверяется по прежнему ключу операции.
- Пакетное задание заканчивается, когда по каждой строке получен результат оформления. Доставка и расчёт отслеживаются по самой заявке.
- В отчёте причина возврата отображается как «неизвестна», пока трекинг не передаст её код.

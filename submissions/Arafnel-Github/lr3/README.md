## Что изменилось относительно черновиков (З-10 – З-13)

1. В черновике З-10 рассматривалась пакетная загрузка `POST /returns/batches`. Для согласования с размыкателем цепи (пункт "в", где оборачивается одиночный вызов `create_return`) в спецификацию вынесена операция создания одиночного возврата `POST /v1/returns`, дополненная получением списка `GET /v1/returns` и отменой `POST /v1/returns/{return_id}/cancel`
2. Двухсостоянийный автомат из практикума расширен состоянием `HALF_OPEN` с лимитом пробных вызовов, таймаутом нахождения в полуоткрытом состоянии (защита от зависания на редких маршрутах) и экспоненциально растущей паузой при повторных неудачах
3. По итогам взаимного аудита в З-12 устранены четыре дыры: для роли "Интеграция" добавлены денежные суточные лимиты и запрет на отмену чужих возвратов; для "Администратора" закрыта лазейка повышения прав через второго администратора; для "Бухгалтера" добавлена операция подтверждения крупных возвратов (`О9`), а избыточный доступ к карточкам отправлений урезан


## Найденные и устранённые расхождения между пунктами

1. В черновике З-12 для операции `О3 (Отменить оформленный возврат)` был указан канал входа только `Экран`, а у роли `Интеграция` клетка была пустой. Однако в ЛР-3 все три операции спецификации пункта "а" должны быть доступны через публичный API. Решение: канал входа для `О3` расширен до `Оба (Экран / API)`, а в матрице прав (`g-access.md`) для роли `Интеграция` разрешена отмена только тех возвратов, которые были созданы этой же интеграцией
2. В черновике З-10 при сбое инфраструктуры возвращался только общий код `500 Internal Server Error`. При внедрении размыкателя выяснилось, что клиент должен отличать падение базы от срабатывания защиты. Решение: в `a-openapi.yaml` и `b-docs.md` добавлен статус `503 Service Unavailable` с заголовком `Retry-After`
3. В З-12 лимиты удержаний были привязаны только к субаккаунтам-людям, что позволяло скрипту интеграции опустошить баланс серией одиночных запросов. Решение: атрибут суточного лимита удержаний распространился на техническую учётную запись роли `Интеграция`

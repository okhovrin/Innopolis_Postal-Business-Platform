## Правило обращения с данными

Репозиторий курса открытый. Данные использованы по правилу:

- **Открытая отчётность организации** - с пометкой [О]
- **Внутренние оценки для целей курса** - не приводятся, заменены на учебные допущения
- **Учебные допущения** - с пометкой [Д] и списком допущений в каждом файле
- **Наименования:**
  - Сервисы самого кабинета - своими именами (Сервис возвратов, REST API, web-client)
  - Смежные корпоративные системы - по функции ("корпоративная шина данных", "тарификатор", "системы финансового учёта")
  - Имена клиентов и партнёров не приводятся

**Обоснование допустимости приведения данных:**

Все количественные данные в работе - либо учебные допущения (порог 1000 возвратов на файл, период опроса 5 минут, размер агрегата витрины), либо взяты из открытых источников курса (состав сервисов системы, протоколы из образца нотации C4). Внутренние метрики организации не раскрываются. Данное правило соответствует требованиям занятия 1 о работе с достоверностью и открытостью репозитория.

## Что изменилось относительно черновиков

Основа - практикумы З-6, З-7, З-8, З-9, схема контейнеров З-5 и согласование входа с З-10.

| Источник | Что сохранено | Что дополнено или уточнено и почему                                                                                                                                                                                                         |
|---|---|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Схема З-5 | Два входа, микрофронтенд, BFF, API Gateway, REST API, отслеживание, Онлайн Баланс, внешние контуры; неизвестные протоколы | Добавлены тарификатор из З-7, воркер и outbox из З-8, аналитический маршрут из З-9. "Статус зачисления" заменён на удержание, списание и освобождение по З-7                                                                                |
| З-6 | Все состояния и переходы, ошибки запрещённых команд, точка невозврата READY → SENDING | Явно показаны ожидание при таймауте, воркер и его поля                                                                                                                                                                                      |
| З-7 | Деньги следуют за приёмом, ключи HOLD/DEBIT/RELEASE, повторное сообщение не списывает деньги снова | Для денежных шагов после REGISTERED показана отдельная модель денежной операции: их нельзя искусственно превращать в переходы заявки. Для корректировки добавлен отдельный устойчивый ключ, чтобы не переиспользовать DEBIT с другой суммой |
| З-8 | Приём 202, ограничения задания, два уровня валидации, три множества результатов, outbox, повторы | Уточнена атомарность отмены и захвата воркером, хранение задания до 202 и восстановление после падения воркера                                                                                                                              |
| З-9 | Вопросы, зерно факта, измерения, дневной агрегат, ELT и requested_reason_code | Заполнены пустовавшие пункты: прослеживаемость, SQL, актуальность и неизвестные значения; добавлен состав события                                                                                                                           |
| З-10 | POST/GET return-jobs и отдельный цикл задания | Формальная проверка конверта идёт до 202, проверка отдельных строк - после.                                                                                                                                                                 |

## Количественные данные

Все лимиты и интервалы обработки - учебные допущения, перенесённые из практикумов: небольшой поток ММСБ, ограниченный входной список, доступность внешних систем для автоматической сверки, поддержка устойчивых ключей операций. Они перечислены рядом с решениями в пункте (а). Числа в SQL, коды HTTP, номера пунктов и кратность факта - элементы спецификации, а не показатели промышленной системы. Внутренние производственные оценки не используются.
